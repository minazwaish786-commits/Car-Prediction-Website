THE MODEL BEHIND THE ESTIMATE

Built on your
ML project.

Your notebook removes Car_Name, predicts Selling_Price, and encodes Fuel Type (Petrol=0, Diesel=1, CNG=2), Seller Type (Dealer=0, Individual=1), and Transmission (Manual=0, Automatic=1).

This standalone website fits an ordinary least-squares Linear Regression model in the browser using all valid uploaded rows. It does not reproduce the notebook's 90/10 evaluation split or its separate Lasso model. Predictions are estimates only.
